\## 화면 구상



\- 앱 이름·주제: 배수의 진. 시험기간에 남은 놀 시간(마지노선)을 보여 주는 앱. 앱 밖 반복 알림은 후속 작업임.

\- 화면의 핵심 사용자 행동: 놀기 전에 값 4가지를 입력해 저장하고, 남은 놀 시간을 확인한다.

\- 위에서 아래로 보여 줄 정보

&#x20; - 입력 화면: 마감 시각 → 필수 생활 시간(시간, 분) → 필요한 공부 시간(시간, 분) → 마감 성적 기준 → 저장 버튼

&#x20; - 타이머 화면: 남은 놀 시간(큰 숫자) → 놀 시간이 없으면 붉은 경고 상자 → 저장한 시각, 마감 시각, 마감까지(저장 시점), 필수 생활 시간, 필요한 공부 시간, 마감 성적 기준 → 다시 입력 버튼

\- 입력·선택·버튼과 그 뒤의 반응

&#x20; - 마감 시각 버튼: 날짜 선택창, 이어서 시각 선택창이 뜨고, 고른 값이 버튼에 표시됨

&#x20; - 시간 칸: 숫자 입력. 음수도 입력할 수 있고, 저장할 때 검사함

&#x20; - 분 칸: 숫자만 입력되고 0\~59만 써짐. 60 이상은 칸에 입력되지 않음. 칸 이름에 0\~59를 표시함

&#x20; - 마감 성적 기준: A+부터 F까지 목록에서 선택

&#x20; - 저장: 검사를 통과하면 타이머 화면으로 이동하고, 실패하면 안내 막대를 띄움

&#x20; - 다시 입력: 타이머 화면을 닫고 값이 남아 있는 입력 화면으로 돌아감. 화면 이동만 함(모드 전환, 알림 취소, 누적 공부 시간 유지는 후속)

\- 사용 전·빈 데이터·잘못된 입력 상태

&#x20; - 처음 실행: 모든 칸이 빈 입력 화면

&#x20; - 잘못된 입력은 안내 막대로 알리고 화면 이동과 저장을 하지 않음. 안내 글자: 마감 시각을 선택하세요 / 마감 시각은 지금보다 뒤여야 합니다 / 시간과 분에는 숫자만 입력하세요 / 필수 생활 시간을 입력하세요 / 필수 생활 시간은 음수일 수 없습니다 / 필요한 공부 시간은 0보다 커야 합니다 / 마감 성적 기준을 선택하세요

&#x20; - 시간 칸과 분 칸 중 한 칸만 비어 있으면 그 칸은 0으로 처리함. 둘 다 비면 비움으로 봄.

&#x20; - 놀 시간이 없는 경우: 남은 놀 시간 00:00:00과 경고 문구를 표시함. 예: 놀 시간이 없습니다. 학점 B를 지키려면 지금 공부해야 합니다. (학점은 선택한 값)

\- PRD 요구 번호와 화면 요소의 연결

&#x20; - R1: 입력 화면의 입력 칸과 저장 버튼

&#x20; - R2: 잘못된 입력 안내 막대

&#x20; - R3: 타이머 화면의 남은 놀 시간과 경고

&#x20; - R4: 다시 입력 버튼

&#x20; - R5: 분 칸의 0\~59 입력 제한

\- 그림이나 화면 구상의 위치: 처음 구상은 9주차 week09/topic.md 2장의 글 스케치임. 이번에 바뀐 점은 다시 입력 버튼 추가이고, 값 수정, 초기화, 놀기와 공부 전환은 후속임. 실행 화면 캡처는 evidence 폴더에 있음. 구상을 이미지로 바꾸라는 말씀(수업 필기 기준)은 아직 반영하지 못했고, 별도의 구상 그림은 만들지 않았음(미작성).

\## 마무리



\- PRD와 다르게 구현된 부분 및 결정 이유: 분 칸 0\~59 입력 제한과 다시 입력 버튼은 구현하면서 정했고 PRD에 반영함. 남은 놀 시간은 저장한 순간의 고정 값이며 줄어들지 않음. 놀기와 공부 전환 버튼이 아직 없어서 정한 설계임.

\- 피드백을 반영해 바꾼 PRD 항목: 핵심 가치에 앱 전체 목표 한 줄 추가(시선 환기), 후속 검토 방향에 공부 방식 피드백 기능 추가(수업 필기 기준)

\- 미완료·미실행과 이유: 남은 놀 시간이 줄어드는 표시, 앱 밖 알림 시험, 폰 안 저장, 자동 테스트, 구상 이미지 그림. 이번 범위 밖이거나 시간 배분 때문에 하지 않음.

\- 아직 검증하지 않은 가정과 다음 질문: 남은 놀 시간이 보이면 놀이 시간을 조절할 것이라는 효과는 아직 써 보며 확인하지 않음. 다른 학생도 같은 어려움이 있는지는 친구 몇 명에게 사례를 물어 확인할 예정임.

\- 11주차에 이어갈 기능·상태·데이터 작업: 놀기와 공부 전환(현재 모드 상태), 남은 놀 시간이 줄어드는 표시, 폰 안 저장, 알림 1회 시험 뒤 반복 알림
